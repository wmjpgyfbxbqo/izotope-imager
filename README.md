## Overview

iZotope Imager is a precision multiband stereo imager that enables independent stereo width control per frequency band for transparent and controlled stereo field management.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Izotope Imager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiband Width** | Independent stereo width per band from narrowing to extreme widening |
| **Correlation Meter** | Phase correlation monitoring per band for out-of-phase detection |
| **Stereoize** | Adds stereo width to mono sources through mid/side processing |
| **Vectorscope** | Real-time stereo vectorscope for visual stereo field analysis |
